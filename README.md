# 📊 Week-4 Data Analysis Projects

This repository contains Python projects that use Pandas and NumPy for real-world data analysis and processing.  
Each project demonstrates how to handle datasets, perform analysis, and generate meaningful insights.

---

## 📂 Projects Included

### 1. Sales Analysis (`sales_analysis.py`)
- Reads and processes sales data  
- Features:
  - Calculates total revenue  
  - Finds the best-selling product  
  - Computes average price and price deviation  
  - Identifies the highest revenue order  
  - Supports product search from store inventory  
  - Saves results to `sales_report.csv`  

---

### 2. Student Performance Analysis (`student_analysis.py`)
- Handles student marks dataset  
- Features:
  - Calculates total marks per student  
  - Finds class topper  
  - Identifies subject-wise toppers  
  - Computes class averages  
  - Sorts students by performance  
  - Saves results to `student_report.csv`  

---

### 3. Supermarket Billing System (`supermarket_billing.py`)
- Simulates a supermarket billing counter  
- Features:
  - Displays available products with stock  
  - Allows user to buy multiple items  
  - Calculates subtotal, discounts, GST, and final bill  
  - Updates stock after purchase  
  - Saves bills to `bill_report.csv` and inventory to `updated_inventory.csv`  

---

### 4. Gym Membership Tracking (`gym_tracking.py`)
- Tracks gym members and their activities  
- Features:
  - Calculates total revenue from memberships  
  - Finds the most active member  
  - Computes average workout hours  
  - Identifies the most popular membership plan  
  - Saves analysis to `gym_report.csv`  

---

### 5. Movie Rating Analysis (`movie_rating.py`)
- Analyzes movie ratings dataset  
- Features:
  - Calculates average rating per movie  
  - Finds the highest-rated movie  
  - Identifies the most reviewed movie  
  - Saves results to `movie_ratings.csv`
